# Drafting tools

Transparent PNG illustrations supplied by Ryan from his Midjourney generations on
2026-11-05, moved from Desktop and renamed for use by `js/draft.js`.

- `pencil.png`: graphite pencil, 121 × 1620; working tip at top center.
- `fountain-pen.png`: black fountain pen, 117 × 1500; working nib at bottom center.
- `eraser.png`: ivory eraser, 583 × 353; working point at center.

The original transparent images are retained at their supplied resolution. CSS
sets display sizes and JavaScript rotates the tools around their working points.
No code or assets from swarm-cursors or the original Swarm site are included.
