# Personal site

Ryan Baltodano's personal site. Separate from the Angrove product site in `../site/` (angrove.app).

- Static HTML/CSS/JS, no build step.
- Own git repo (ignored by the parent `angrove-project` repo). No remote or domain yet.
- Style: editorial serif with plotted maths; see `DESIGN.md`. Held to the Hallmark gates (sloplint).

Run locally: `python3 -m http.server 8010` from this folder (or the `personal-site` launch config).
