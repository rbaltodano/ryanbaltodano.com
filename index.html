Selected work · 2026

Angrove

iPhone beta on TestFlight · Mac in development · Solo since April 2026

A private AI study workspace for philosophy, history, and theology. Ask a question, check the primary sources behind the answer, and save the ideas worth keeping in a semantic map. Everything runs on the device: no model server, no account, works offline.

On-device LLMGemma 4 E4B on LiteRT-LM. No model server, works offline.
51,836 passagesSearched locally with Core ML MiniLM embeddings.
iPhone + MacOne SwiftUI codebase, native on each platform.
AES-256-GCMEncrypted personal data with Keychain-managed keys.
900+ testsBehavior and regression coverage across both apps.
End to endDesign, engineering, evaluation, and release.

Engineering highlights

The hard parts, and the code.

One model, many jobsModelTaskQueue.swift

Answers, definitions, and tree updates all compete for a single on-device model. A shared task queue serializes them with cancellation and reordering, and a lifecycle manager handles loading, idle unloading, and background transitions. The card beside this list is that queue, running practice tasks.

Read ModelTaskQueue.swift
Grounded answers, offlineMiniLMGroundingProvider.swift

A bundled library of 37 primary works is embedded and searched on the phone. Source routing and passage locators pick the text a question actually needs, and answers link back to the passages they drew on.

Read MiniLMGroundingProvider.swift
Encryption without data lossLocalDataEncryption.swift

Saved personal data is encrypted at rest with per-platform Keychain keys. Startup validates ciphertext and migrates existing plaintext installs in place, covered by migration regression tests.

Read LocalDataEncryption.swift
Two native apps, one coreMacWorkspaceView.swift

Conversation, persistence, retrieval, and design-system code live in a shared layer. Each platform owns its navigation, windows, and input, so the Mac app feels like a Mac app rather than a stretched phone.

Read MacWorkspaceView.swift

Decisions backed by measurement

The model's native “thinking” mode roughly doubled answer time without improving objective passes across two evaluation sets, so it ships off by default. Read the comparison.

About

Design and engineering as one decision.

I started as a web designer and became a software engineer by building the things I wanted to exist. Angrove began when I learned a capable language model could run entirely on a phone, and I wanted to see what a private, thoughtful AI tool could look like end to end.
