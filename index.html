02 / Research software

inVectus

A local-first research tool for Mac. Map a collection of papers, find gaps in its coverage, and inspect the evidence behind each one.

Source & project notes ↗
MacReact · TypeScript · RustIn development

Interface notes

Select a number on the image or a note below.

Demand, coverage, and activity appear above the score breakdown. The numbers behind a flagged gap remain visible.

The selected gap stays marked on the collection map beside its evidence. Its position can be read in the context of the other papers.

The flag describes coverage within this collection. It does not establish that an idea is globally novel.

04 / Practice

How I work

I design the interface, write the code, and check that it holds up before it ships.

  1. 01Interface

    Design it first

    Every screen starts in Figma: components, type, and the interaction patterns between screens.

  2. 02Code

    Then build it myself

    SwiftUI for Angrove on iPhone and Mac. React, TypeScript and Rust for inVectus.

  3. 03Test

    Check that it holds up

    Before choosing Angrove's default, I ran it through an 80-case evaluation.

  4. 04Ship

    Put it in people's hands

    Angrove is in public beta on iPhone through TestFlight, and the Mac app arrives December 15.
